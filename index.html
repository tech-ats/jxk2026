✅ 0단계 — 내 계정에 Copilot이 켜졌는지 확인

해커톤 운영진이 여러분의 개인 GitHub 계정에 Copilot 라이선스(좌석)를 부여했습니다. 먼저 확인부터 하세요.

1
초대 수락: 이메일 또는 GitHub 알림으로 온 조직 초대(Invitation)를 수락하세요. 제목 예: You've been invited to join … → Join / Accept invitation 클릭.
2
라이선스 확인: 브라우저에서 https://github.com/settings/copilot 접속. 페이지 상단에서 " GitHub Copilot Business is active for your account" 메시지가 표시되면 준비 완료 ✅
3
안 보이면? ① 초대를 수락했는지 ② 운영진이 좌석을 할당했는지 확인. 그래도 없으면 운영진에게 본인 GitHub 사용자명(username)을 알려 좌석 할당을 요청하세요.
GitHub 계정이 아직 없다면 https://github.com/signup 에서 먼저 무료 가입 후, 그 사용자명을 운영진에게 전달하세요.

🧩 도구별 설치 · 로그인

본인이 사용할 환경을 골라 그 탭만 따라 하면 됩니다.

Copilot in your IDE 가장 추천

VS Code · Visual Studio · JetBrains 등 코드 편집기에서 자동완성과 채팅을 사용합니다. 아래에서 본인 편집기를 고르세요.

📖 공식 문서: IDE에서 코드 제안 받기

Visual Studio Code 초보자 추천

최신 VS Code에는 Copilot이 기본 내장되어 있어 대부분 로그인만 하면 됩니다.

1
VS Code 설치: 없다면 https://code.visualstudio.com 에서 내려받아 설치. (최신 버전 권장)
2
Copilot 아이콘 확인: 창 오른쪽 위 또는 상단 가운데의 Copilot 아이콘(말풍선)을 클릭. 없으면 왼쪽 Extensions(⧉)에서 GitHub Copilot 검색 → Install.
3
로그인: 안내 팝업의 Sign in to GitHub 클릭 → 브라우저에서 본인 GitHub 계정 로그인 → Authorize. (또는 왼쪽 아래 계정 아이콘 👤 → Sign in)
4
확인: 코드를 치면 회색 제안(고스트 텍스트)이 뜨면 성공 ✅ · Tab 으로 수락.
Copilot Chat 열기: 사이드바 Copilot 아이콘 또는 Ctrl+Alt+I (Mac: ⌘+⌥+I).

Visual Studio (2022)

1
버전 확인: Visual Studio 2022 17.10 이상 권장. 최신 Copilot은 기본 포함. (Visual Studio Installer에서 업데이트)
2
로그인: 오른쪽 위 계정 아이콘 또는 GitHub Copilot 배지 클릭 → Sign in → 본인 GitHub 계정 로그인·인증.
3
수동 설치가 필요하면: 확장(Extensions) → 확장 관리에서 GitHub Copilot 검색 후 설치·재시작.
4
확인: 코드 편집 중 회색 제안이 뜨면 성공. Chat은 Copilot Chat 창에서 사용.

JetBrains IDE (IntelliJ · PyCharm · WebStorm 등)

1
플러그인 설치: Settings/Preferences → Plugins → Marketplace에서 GitHub Copilot 검색 → Install → Restart IDE.
2
로그인 시작: 상단 메뉴 Tools → GitHub Copilot → Login to GitHub 클릭.
3
기기 코드(device code) 인증: 뜨는 코드를 Copy and Open → 브라우저 로그인 후 코드 붙여넣기 → Continue → Authorize.
4
확인: IDE로 돌아오면 로그인 완료. 코드 작성 시 제안이 뜨고, 우측 Copilot Chat 패널 사용 가능 ✅

Copilot CLI 터미널

터미널(명령줄)에서 Copilot에게 명령어를 물어보고 실행할 수 있습니다. 셸 명령이 헷갈릴 때 유용합니다.

📖 공식 문서: Copilot CLI 개요

1
GitHub CLI 설치: https://cli.github.com 에서 gh 설치. (Windows는 winget install GitHub.cli 도 가능)
2
로그인: 터미널에서 gh auth login 실행 → 브라우저 인증으로 본인 계정 로그인.
3
Copilot 확장 설치: gh extension install github/gh-copilot
4
사용: gh copilot suggest "폴더 안 큰 파일 찾기" (명령어 제안) · gh copilot explain "tar -xzf a.tar.gz" (명령 설명)
최신 독립형 copilot CLI를 안내받았다면 문서의 설치 지침을 따르세요. 로그인은 동일하게 본인 GitHub 계정을 사용합니다.

Copilot app (GitHub App)

Copilot을 여러분의 저장소·조직에 연결해 PR, 이슈 등에서 활용하도록 돕는 GitHub App입니다.

📖 공식 안내: GitHub Copilot App

1
위 링크(github.com/features/ai/github-app) 접속 → 설치/추가 버튼 클릭.
2
본인 계정 또는 대상 저장소·조직을 선택해 앱을 설치하고 권한을 승인합니다.
3
설치 후, 연결된 저장소의 이슈·PR 등에서 Copilot 기능을 사용할 수 있습니다.
조직에 앱을 설치하려면 조직 관리자 권한이 필요할 수 있습니다. 안 되면 해커톤 운영진에게 문의하세요.

Chat in GitHub Mobile 📱 이동 중

휴대폰의 GitHub 모바일 앱에서 Copilot Chat으로 질문하고 코드 설명을 받을 수 있습니다.

📖 공식 문서: GitHub Mobile에서 Copilot 채팅

1
앱 설치: App Store / Google Play에서 GitHub 앱 설치 → 본인 계정 로그인.
2
Copilot 열기: 앱 내 Copilot(말풍선) 아이콘을 눌러 채팅 시작.
3
사용: 자연어로 질문하거나, 저장소를 지정해 코드·이슈에 대해 물어보세요.

Copilot in GitHub.com 🌐 브라우저

설치 없이 브라우저에서 바로 Copilot Chat을 사용합니다.

📖 공식 문서: GitHub에서 Copilot 채팅

1
https://github.com/copilot 접속 → 본인 계정 로그인.
2
질문 입력창에 자연어로 질문. 저장소(repo)를 지정하면 그 코드 기준으로 답합니다.
3
저장소 화면 우측 상단의 Copilot 아이콘으로 "이 repo에 대해" 물어볼 수도 있습니다.
웹·모바일 Chat은 대화·질문·코드 설명에 좋고, 실제 자동완성(고스트 텍스트)은 IDE에서 됩니다.

More features

Copilot의 전체 기능(코드 리뷰, PR 요약, Agent, 확장 등)은 아래 공식 문서에서 확인하세요.

📖 공식 문서: GitHub Copilot 기능 모음

  • 코드 자동완성 — 입력 중 다음 코드 제안
  • Copilot Chat — 자연어로 질문·수정·설명
  • Agent 모드 — 여러 파일에 걸친 작업 자동 수행
  • 코드 리뷰 / PR 요약 — 변경사항 요약·리뷰 도움
  • CLI · 모바일 · 웹 — 편집기 밖에서도 사용

💬 사용법 3가지

1. 자동완성 (Code Completion)

코드를 치면 회색 고스트 텍스트로 다음 코드를 제안합니다.

  • Tab = 수락 · Esc = 거절
  • Alt+] / [ = 다른 제안 보기
  • 주석으로 원하는 걸 적으면(예: // 이메일 형식 검증 함수) 그에 맞는 코드를 제안

2. 채팅 (Copilot Chat)

자연어로 물어보세요. "이 함수 설명해줘", "버그 찾아줘", "테스트 코드 만들어줘" 등.

  • 코드를 드래그해서 선택한 뒤 물어보면 그 코드 기준으로 답합니다.
  • 슬래시 명령: /explain 설명 · /fix 수정 · /tests 테스트 생성 · /doc 문서화

3. Agent 모드 (여러 파일 자동 작업)

VS Code 등에서 Chat 상단의 모드를 Agent로 바꾸면, 요청을 여러 파일에 걸쳐 스스로 수정·실행합니다. "로그인 페이지 만들어줘" 같은 큰 작업에 유용.

Agent가 제안한 변경은 내용을 확인하고 승인한 뒤 적용하세요. 항상 결과를 검토하는 습관이 중요합니다.

🎛️ 모델 선택 — 어떤 AI를 쓸지 고르기

Copilot Chat에서는 여러 AI 모델 중 하나를 골라 쓸 수 있습니다. 작업 성격에 따라 바꿔 보세요.

고르는 위치

1
VS Code / Visual Studio / JetBrains: Copilot Chat 입력창 아래(또는 옆)의 모델 이름 드롭다운을 클릭 → 목록에서 모델 선택.
2
GitHub 웹(github.com/copilot): 채팅 상단/입력창 근처의 모델 선택 드롭다운에서 변경.

어떤 모델을 언제?

⚡ 기본(자동 선택 / 빠른 모델)

일상적인 자동완성·간단한 질문에 적합. 응답이 빠르고 크레딧 소모가 적습니다. 대부분 이걸로 충분.

🧠 고성능 추론 모델 (예: GPT·Claude 계열 상위 모델)

복잡한 로직 설계, 어려운 버그 분석, 긴 코드 리팩터링에 유리. 대신 응답이 느리고 AI 크레딧을 더 많이 씁니다.
해커톤 팁: 크레딧 예산이 걸려 있으니 평소엔 기본/빠른 모델을 쓰고, 정말 어려운 문제에서만 고성능 모델로 바꿔 쓰면 크레딧을 아낄 수 있습니다.
선택 가능한 모델 목록은 운영진의 정책 설정에 따라 다를 수 있습니다. 드롭다운에 보이는 모델만 사용 가능합니다.

🆘 잘 안 될 때 (Troubleshooting)

증상해결
제안이 안 뜬다로그인 상태 확인(계정 아이콘) · 상태바 Copilot 아이콘이 켜졌는지 · IDE 재시작
"No access / 라이선스 없음"github.com/settings/copilot에서 Active인지 확인 · 아니면 운영진에 좌석 요청
로그인 후에도 안 됨계정 아이콘 → Sign out 후 다시 로그인 · 확장 최신 버전으로 업데이트
모델이 안 보인다운영진 정책상 제한일 수 있음 · IDE·확장 업데이트 후 재시도
회사 방화벽/네트워크일부 네트워크가 GitHub 연결을 차단할 수 있음 · 다른 네트워크(핫스팟)로 시도
이 가이드는 개인 GitHub 계정 기준입니다. 참가자는 본인 계정으로 로그인하며, 좌석·정책은 해커톤 운영진이 관리합니다.
막히면 운영진에게 본인 GitHub username, 사용 IDE, 오류 메시지 스크린샷을 함께 전달하면 빠르게 해결됩니다.
